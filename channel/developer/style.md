# Alex Astro

Alex Astro makes developer sketches and explainers. Start with an action the viewer can follow, such as a request moving through a queue or a failed build that changes the conversation. Keep the same object visible as its state changes.

Stage dialogue with pixel characters and place captions near the speaker. For a close-up, pair the speaker's anime portrait with the words over a quiet background. Time gestures and interface changes to the dialogue. Save voice and asset choices in the episode's local production records.
