# Norbert Explains

Norbert Explains combines motion graphics and pixel characters for everyday explainers. Put the question on screen with a recognizable action. Carry the same object into the next beat so the explanation changes something the viewer can see.

Use one focal point and time highlights to the spoken subject. Put short captions between the center and bottom, clear of faces and hands. Match sounds to contact and movement. Use the episode manifest to set the format and timing.
